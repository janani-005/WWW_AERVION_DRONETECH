# AERVION DRONETECH SOLUTIONS PVT. LTD. - Corporate Website

A premium, modern, lightweight, and production-ready static corporate website for **AERVION DRONETECH SOLUTIONS PVT. LTD.** based in Salem, India.

> **Source of Truth**: All company overview content, vision, mission, core values, services, technological capabilities, and contact details are strictly derived from the official company profile `AERVION PROFILE.docx`.

---

## Technical Architecture & Stack

- **Core**: Semantic HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Frameworks / Libraries**: 0 External JS Frameworks (No React, Vue, Next.js, Bootstrap, Tailwind, or jQuery).
- **Styling**: Vanilla CSS with custom CSS variables, HUD technical overlays, responsive Flexbox/Grid systems, and glassmorphism UI.
- **Performance**: Optimized load times, responsive SVG graphics, dynamic scroll observer (`IntersectionObserver`).

## How to Run Locally

You can serve the static site using any local HTTP server:

### Using Python (Built-in)
```bash
# In project root directory:
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.
